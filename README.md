# 电商工具

先选平台，再选功能。平台有速卖通、虾皮、希音、亚马逊。每个平台下面有运费计算、素材生成。现在接上的只有速卖通的运费计算。

文字翻译和视频翻译是通用功能，记在 `shop/shopapp/catalog.py`，不挂在某个平台下面。文字翻译填写原文并选择输入、输出语言。视频翻译上传视频并选择输入、输出语言，按说话内容生成带译文字幕的视频，原来的声音保留。视频请短于 3 分钟、小于 80MB。第一次翻译视频会加载语音模型。

新平台加在这份目录里。某个平台的运费要真正计算时，再在 `shop/shopapp/platforms/` 增加实现，并把该功能的 `ready` 改成 true。

## 运行

```bash
pip install -r requirements.txt
python -m shop.server
```

打开 http://127.0.0.1:3460 。

## 运费

配送服务费在物流费表里的单位是元/千克。实际运费 = 计费重量(kg) × 配送服务费 + 挂号费。佣金比例是页面上六项成本相加，运费成本合计 = 实际运费 × (1 + 佣金比例)。改了任何一项，就按新的合计计算。成本不超过包邮基准的国家记为包邮。批量导入时一个 SKU 一份运费表。

页面可以上传新的物流费表。上传之后，渠道列表和全部计算都改用新表。

`shop/data/default_rates.xlsx` 是上传的物流费表，渠道是其中除「目录」以外的每个 sheet。这份表没有 DHL。页面再上传新表后，渠道和计算都改用新表。
