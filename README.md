# 电商工具

先选平台，再选功能。平台有速卖通、虾皮、希音、亚马逊。每个平台下面有运费计算、素材生成。现在接上的只有速卖通的运费计算。

文字翻译和视频翻译是通用功能，记在 `shop/shopapp/catalog.py`，不挂在某个平台下面。

新平台加在这份目录里。某个平台的运费要真正计算时，再在 `shop/shopapp/platforms/` 增加实现，并把该功能的 `ready` 改成 true。

## 运行

```bash
pip install -r requirements.txt
python -m shop.server
```

打开 http://127.0.0.1:3460 。

## 运费

配送服务费在物流费表里的单位是元/千克。产品运费 = 计费重量(kg) × 配送服务费 + 挂号费。表头是「0.5KG 首重 + 每 500G 续重」时，用首重运费加上超出首重的档数乘续重单价。产品最终运费再乘上六项成本比例，金额保留两位小数。

页面可以上传新的物流费表。上传之后，渠道列表和全部计算都改用新表。

`shop/data/default_rates.xlsx` 是上传的物流费表，渠道是其中除「目录」以外的每个 sheet。这份表没有 DHL。页面再上传新表后，渠道和计算都改用新表。
